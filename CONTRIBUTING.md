# Contributing

made by jared castorena 1728studios llc

Keep the starter small, portable and honest about its limits. Prefer standard-library implementations and focused tests. Keep actual project memories, identities, logs, private paths and task-specific stories out of examples.

Describe a concrete problem, the changed behavior and how it was checked. Preserve failing evidence when it matters; do not add a coordination process without a demonstrated need. Changes to format or command behavior must update the protocol, CLI guide, manifest and relevant tests together.

No formal license is included. Please read ATTRIBUTION.md and do not add a license or mandatory attribution condition without the maintainer's approval.
